# mecanica-social-institucional

Sitio web institucional de la ONG Mecánica Social: estrategia, marketing y gestión organizacional.

Presenta a la Escuela de Formación como core business de la ONG y utiliza
mecanica-social-ia (repositorio privado por ahora) como canalizador de solicitudes.

## Ecosistema

| Repositorio | Rol |
|---|---|
| mecanica-social-institucional | Página principal, estrategia y gestión (este repositorio) |
| mecanica-social-escuela | Programas, recursos y evidencias formativas |
| mecanica-social-ia | Sistema institucional de inteligencia artificial |
| mecanica-social-biblioteca | Fuentes, bibliografía y conocimiento (pendiente) |

## Estructura

- `site/index.html`: la página web.
- `.github/workflows/pages.yml`: publica la carpeta `site/` en GitHub Pages.
- `SECURITY.md`, `AI_ETHICS.md`, `CODE_OF_CONDUCT.md`: reglas de seguridad, uso de IA y convivencia.

## Cómo modificar la página

1. Abre `site/index.html` en GitHub y pulsa el lápiz para editar.
2. Pulsa **Commit changes**.
3. En 1 o 2 minutos la página se actualiza sola.

## Advertencias

- Las cifras del plan 2027-2029 son hipótesis de planificación, no asesoría financiera.
- El formulario de contacto es demostrativo y no envía datos.
- Licencia: pendiente de definición institucional.

## Principios

Supervisión humana, transparencia sobre el uso de IA, protección de datos y neutralidad institucional.
