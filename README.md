# mecanica-social-institucional

Sitio web institucional de la ONG Mecánica Social: estrategia, marketing y gestión.
Presenta a la Escuela de Formación como core business y usa mecanica-social-ia como canalizador.

## Publicación
GitHub Pages desde la carpeta `site/` mediante `.github/workflows/pages.yml`.

## Antes de publicar
En `site/index.html` cambia `TU-USUARIO` por tu usuario de GitHub.

## Principios
Supervisión humana, transparencia sobre el uso de IA y cifras como hipótesis de planificación.
