# 💼 Repositorio Institucional - ONG Mecánica Social

Base de datos documental y estratégica de la administración central de la ONG Mecánica Social.

## 🗺️ Arquitectura del Ecosistema Organizacional
La organización opera bajo un modelo de plataforma unificada enfocado en la **Escuela de Formación Política "Marcelo Orellana Lagos"** como núcleo del ecosistema:
- **La Escuela:** Interfaz principal de cara al usuario, malla curricular y la Consola de Admisión.
- **La Biblioteca:** Módulo interno encargado de almacenar, indexar y validar el conocimiento técnico regulatorio.
- **IA Sandbox:** Procesador de inteligencia artificial que consume de forma exclusiva los contenidos autorizados de la Biblioteca.
