# Seguridad

No incorporar al repositorio:

- contraseñas, tokens ni claves API;
- datos personales innecesarios;
- evaluaciones individuales;
- documentos reservados;
- información financiera sensible.

Si detectas una exposición de datos o credenciales, no la publiques como incidencia abierta: avisa de forma privada a la Dirección Ejecutiva de la ONG.
